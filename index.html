CAPTION LAB

Gerador de tipografia animada para legendas de Reels. Cada linha do roteiro vira um bloco: a primeira linha é o título (abertura trabalhada), as seguintes são legendas simples. Use | dentro de uma linha para forçar quebra (útil no título) e *palavra* para marcar uma palavra em vermelho manualmente.
